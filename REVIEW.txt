Codexion implementation review
Date: 2026-10-29

Implemented
- Per-coder completed compile count and shared completion stop decision.
- Repeated acquire, compile, release, debug, refactor lifecycle. The final
  compile skips debug and refactor.
- Separate deadline monitor. The arbiter mutex protects stop, compile counts,
  compile start times, and the ordering of state and burnout messages.
- One coder takes its only dongle and waits for the monitor to report burnout.
- FIFO requests carry an arbiter-assigned sequence for equal-millisecond order.
- Equal-deadline EDF requests favor alternating seats to allow independent
  pairs to compile concurrently; earlier deadlines still take precedence.

Verification
- make and git diff --check: passed.
- 108 initial lifecycle matrix runs: passed for 1, 2, 3, 4, 10, and 100
  coders, both schedulers, three duration sets, three repetitions.
- 30 final lifecycle/cooldown runs: passed for 2, 3, 4, 10, and 100 coders,
  both schedulers, three duration sets. Each coder performed three compiles;
  adjacent compile starts respected compile time plus cooldown.
- 60 repeated-cycle EDF runs: passed for 3, 4, 10, and 100 coders, three
  parameter sets, five repetitions each. A prior EDF tie rule failed at 100
  coders; these checks passed after the tie rule change.
- Forced burnout during compile, debug, refactor, and dongle waiting: passed
  under FIFO and EDF, with one final burnout line each.
- 80 burnout timing runs at 1, 2, 10, and 100 coders: observed log delay
  relative to the configured deadline ranged from 0 to 3 ms.
- Heap unit check: equal-millisecond FIFO sequence and EDF ordering passed.
- Fault-injected pthread_create failures at calls 1, 2, 3, 5, and 101:
  program exited with status 1 promptly in each case.
- AddressSanitizer and UBSan: passed at 100 coders with leak detection off.
- Manual line-length and function-size checks: passed.

Unverified
- No separate correction PDF was present in the workspace; only the subject
  PDF at src/codexion.pdf was available.
- norminette, Valgrind, and Helgrind were unavailable.
- LeakSanitizer could not run under this environment's ptrace restrictions.
- ThreadSanitizer runs were unreliable due to unexpected memory mapping errors.
- Finite EDF tests do not prove starvation freedom for every feasible setup.
- Condvar timed waits use CLOCK_REALTIME; a system clock jump can affect waits.
